# A2 remote artifact bundle

This directory contains the Git-hosted, reviewer-facing evidence for the frozen
A2 benchmark. It retains the complete 1,200 episode records (600 each for H16
and H8), run manifests and summaries, aggregate metrics with confidence
intervals, per-condition/per-case tables, A1-paired ablations, provenance,
checksums, and the report figure.

The local raw artifact also contains 4,804,866,822 bytes of decision JSONL and
25,972,674,712 bytes of merged frame bundles, plus resumable worker shards.
Those files are not committed because each decision log exceeds GitHub's
per-file limit and the complete raw tree is unsuitable for Git history. Their
exact byte counts and SHA-256 digests are recorded in
`reviewer/artifact_inventory.json` so an independently transferred raw bundle
can be verified.

The results were generated by `scripts/run_a2_full_benchmark.sh` from the exact
frozen A1 `GR00T-RC` checkpoint with the outcome-blind 150-step hierarchy:

- H16: 600 episodes; primary task-macro predicate SR 0.02799101824101824;
  terminal goal-state SR 0.021666666666666667.
- H8: 600 episodes; primary task-macro predicate SR 0.026521177896177896;
  terminal goal-state SR 0.021666666666666667.
- Paired A2-A1 paper-SR delta: +0.0009208939208939208 for H16 (95% CI crosses
  zero) and -0.0013454970954970954 for H8 (95% CI crosses zero).

The fixed hierarchy therefore has no statistically supported improvement over
A1 on this continuous no-restore track. This negative result is retained rather
than tuning the hierarchy on full-test outcomes.

See `reviewer/REVIEWER_REPORT.md` for definitions, confidence intervals,
condition breakdowns, limitations, and the frozen protocol.
