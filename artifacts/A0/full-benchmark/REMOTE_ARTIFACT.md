# A0 remote artifact bundle

This directory contains the Git-hosted, reviewer-facing evidence for the frozen
A0 benchmark. It retains the complete 1,200 episode records (600 each for H16
and H8), run manifests and summaries, aggregate metrics with confidence
intervals, per-condition/per-case tables, provenance, checksums, and the report
figure.

The local raw artifact also contains 4.72 GB of decision JSONL and 22.0 GB of
deduplicated frame bundles (plus resumable worker shards). Those files are not
committed because individual decision logs exceed GitHub's per-file limit and
the complete raw tree is not suitable for Git history. Their exact byte counts
and SHA-256 digests are recorded in `reviewer/artifact_inventory.json` so a raw
bundle can be verified independently.

The results below were generated by `scripts/run_a0_full_benchmark.sh`:

- H16: 600 episodes; primary task-macro predicate SR 0.03771039146039146;
  terminal goal-state SR 0.015.
- H8: 600 episodes; primary task-macro predicate SR 0.05047518685018685;
  terminal goal-state SR 0.021666666666666667.

See `reviewer/REVIEWER_REPORT.md` for definitions, confidence intervals,
condition breakdowns, limitations, and the frozen continuous no-restore
protocol.
